# Amazon Fire-tablet submission preparation

Status: **not submitted**. Do not mark physical testing, live services or privacy
requirements complete without actual evidence.

- Working title: LIFEVERSE AI — interface preview.
- Category proposal: Productivity.
- Current behavior: Home Universe, animated orb, navigation, Interface Studio and
  appearance controls. Account/data/AI services are unconfigured in this build.
- Do not promise live AI, calendar connectivity, saved private records or an
  operational cloud service in a preview listing.
- Target consideration: compatible Fire tablets only after physical Fire OS
  testing. The current smaller APK has an ARM64 runtime; some Fire tablets need
  an ARMv7 build. Do not select all devices by assumption. Fire TV and Vega OS
  require separate input/platform support and testing.
- Publisher identity, support contact, data disclosures, finalized privacy URL,
  age/content answers and territorial choices must match the actual operator
  and deployment. No placeholder or invented legal information should be submitted.
- Native screenshots must come from the tested Fire device; web illustrations
  are not evidence of Fire-tablet compatibility.

The website's preview-information page is explanatory, not a completed production
privacy/legal review. Full-account export/deletion, live-service configuration,
credential recovery and the remaining Phase 7 release gaps must be accounted for.

The official Amazon process requires a developer account and a physical device
test. Amazon does not currently accept new general Android-phone submissions.
See [PUBLIC_RELEASE.md](PUBLIC_RELEASE.md) for verified policy sources and the
existing signed-preview build details.
