PREVIEW INFORMATION

Privacy starts with clarity.

This download website introduces a personal interface preview. It does not provide a live AI service or account backend.

The download page

No advertising or analytics scripts are installed. The page uses Google Fonts, which makes font requests to Google. Hosting providers process ordinary connection information such as IP addresses and request logs. The current signed APK is hosted on this website. Older preview downloads link to public GitHub release assets.

The app preview

Appearance and motion preferences can be saved locally. Sign-in, private records, calendar integrations and real AI require separately configured services and are unavailable in the unconfigured preview. Do not submit sensitive data for this interface test. Native Android permissions remain subject to your device settings.

Future online services

The repository contains account, AI, calendar and storage features, but their presence in source code is not a claim of an operating hosted service. Before a full public release, a named operator, privacy contact, actual service providers, full-account deletion/export, retention and production security controls must be finalized.

Source and current limits

Review the project source and verification documents on GitHub. This preview is not an Appstore approval, medical service or financial service.
