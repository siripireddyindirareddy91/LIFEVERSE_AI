A little clarity.

Is this free to try?

Yes. This interface preview is free to download. No backend subscription or store account is required to inspect it. Online services have not been deployed.

Can I use it on an iPhone?

You can open the web preview in Safari. An Android APK cannot be installed on iOS, and no native iPhone release is available yet.

Why does Android mention an existing app or signature?

The newer separately signed build cannot update an older debug-signed preview. Uninstalling an old app erases its local data; only do so if you intend to discard that data. The release page identifies the signing/build type.

Are the APKs stored on Cloudflare Pages?

The optimized signed APK is hosted directly on this website. Older, larger preview builds remain available in GitHub Releases.

Is the app in the Amazon Appstore?

No. Amazon submission is pending developer setup, Fire-tablet testing and completion of release requirements. This page does not claim store approval.
